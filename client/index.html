Make a Fighter

  1. Clone the repo and run npm install.
  2. Run npm run new-character -- your-name. This creates characters/your-name/character.js.
  3. Open Claude Code in the repo and describe your fighter: their look, personality, moves, specials. Claude reads CLAUDE.md and the guides in docs/.
  4. Run npm run dev and open http://localhost:3000/?train=your-name to try them in Training (press H to see hitboxes), and /lab.html?char=your-name for the Art Lab — every pose and move, hitbox overlays, forms and art checks.
  5. Run npm run validate. Anything too strong gets scaled automatically — the report shows what changed.
  6. Open a pull request. Once merged, Render redeploys and everyone can play your fighter online.

Go wild. Big numbers are fine — the auto-balancer keeps every fighter fair, so nobody can one-shot or become unkillable.
